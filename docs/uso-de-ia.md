# Uso de IA

Durante o desenvolvimento do projeto, utilizamos Inteligência Artificial apenas como ferramenta de apoio para entender conceitos, revisar decisões e ajudar na organização das etapas.

Antes de pedir qualquer orientação, alimentamos a IA com:

• o PDF oficial do projeto;
• os slides disponibilizados pelo professor;
• o repositório de exemplo da disciplina.

A intenção foi manter todas as sugestões alinhadas ao conteúdo ensinado em sala e ao que foi solicitado no projeto.

## Exemplos de prompts utilizados

### Nestor Melquezedeque

> Estou fazendo um projeto de faculdade em Java com mais dois colegas. Vou te enviar o PDF do projeto, os slides do professor e o repositório de exemplo dele. Quero que você use esses materiais como base para me ajudar durante o projeto. Não invente requisitos e não complique a arquitetura. O projeto deve continuar simples e próximo do que foi ensinado em sala.

> Agora quero implementar apenas a versão sequencial do projeto. Use o PDF, os slides e o código de exemplo do professor como referência. Quero manter o método de cálculo, matriz determinística, processamento sequencial e medição com System.nanoTime. Não implemente paralelismo ainda.

### José Vitor

> Minha parte do trabalho é implementar o paralelismo não estruturado. Use como base o PDF do projeto, os slides do professor e o repositório de exemplo da disciplina. Me explique de forma simples como o ExecutorService funciona, o que é thread pool, Future e por que precisamos chamar shutdown.

> Analise minha implementação com ExecutorService usando como referência o PDF, os slides e o repositório do professor. Confira se a matriz foi dividida corretamente, se os resultados parciais são somados corretamente e se o executor é encerrado com shutdown.

### Flávio Barbosa

> Minha parte é implementar concorrência estruturada. Use como base o PDF do projeto, os slides do professor e o repositório de exemplo da disciplina. Me explique de forma simples a diferença entre ExecutorService e StructuredTaskScope.

> Agora preciso adicionar estado compartilhado à versão estruturada. Use o PDF, os slides e o repositório do professor como referência. Me explique o que é uma race condition e como uma coleção concorrente pode ser usada nesse caso.

## Validação

As orientações recebidas foram revisadas pelo grupo e comparadas com:

• o PDF oficial do projeto;
• os slides das aulas;
• o repositório de exemplo do professor;
• os testes realizados localmente.

A IA foi utilizada como apoio ao desenvolvimento e ao estudo, e não como substituição do entendimento técnico dos integrantes.
